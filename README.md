# Industrial Bolt Defect Detection

A deep learning-based computer vision project for detecting defective and non-defective industrial bolts from images.

## Project Overview

The project explores automated visual inspection of industrial bolts using deep learning.

Two different approaches were implemented and compared:

- A CNN model built from scratch
- EfficientNetB5 using transfer learning with ImageNet weights

## Key Features

- Industrial bolt image classification
- Image preprocessing with OpenCV
- Data augmentation
- CNN-based image classification
- EfficientNetB5 transfer learning
- Training and validation
- Image and video inference
- Defective / non-defective classification

## Technologies

- Python
- TensorFlow / Keras
- EfficientNetB5
- OpenCV
- NumPy
- Matplotlib
